Desktop Automation Agent

A modular automation platform that controls your computer like a human — filling ERP forms, web forms, and any desktop app from a spreadsheet. No coding required.

✓ No command line needed
✓ Works on any Windows PC
✓ Reads Excel & CSV files
✓ Handles errors & retries
✓ Resume after crashes
✓ Add new workflows easily
📖 Overview

What This Tool Does

The Desktop Automation Agent reads rows from your spreadsheet and automatically types the data into any application — ERP systems, web portals, desktop software — exactly as a human would, but faster and without mistakes.

It controls the mouse and keyboard, reads your Excel or CSV file, detects buttons and fields on screen, handles errors and retries, and keeps a live log of everything it does.

The app is designed to be shared across a team. Each person installs it once, then uses a simple GUI window — no terminal, no Python knowledge needed.

📦 Installation

Deploying to a Windows Computer

Follow these steps on each computer where the agent will run. Steps 1 and 2 are one-time setup only.

1

Install Python

Open a browser and go to python.org/downloads. Click the big yellow Download button and run the installer.

⚠️
Critical step — do not skip this On the first screen of the Python installer, check the box at the bottom that says "Add Python to PATH" (or "Add python.exe to PATH"). Then click Install Now.
💡
Already installed but getting errors? The new install.bat automatically searches all common Python install locations — even if it's not in PATH. You don't need to fix PATH manually anymore.
2

Extract the zip and run the installer

Right-click desktop_automation_agent.zip → Extract All → choose a folder (e.g. C:\DesktopAgent\).

Open the extracted folder and double-click install.bat.

A black window will appear and install all required packages automatically. This takes 1–3 minutes on first run. When it says "Installation Complete!", press any key to close it.

ℹ️
If Windows asks "Do you want to allow this app to make changes?" Click Yes. This is normal — the installer needs permission to install Python packages.
3

Launch the application

Double-click Run Desktop Agent.bat to open the application. You can also create a shortcut to this file on the desktop.

💡
Create a desktop shortcut: Right-click Run Desktop Agent.bat → Send to → Desktop (create shortcut). Rename it to "Desktop Agent" for easy access.
▶️ First Run

Running Your First Automation

1

Select a workflow

In the Workflow dropdown at the top of the left panel, choose erp_data_entry (or whichever workflow applies to your task).

2

Load your spreadsheet

Click Browse next to "Data File" and select your Excel (.xlsx) or CSV file. The filename will appear in the panel.

A sample file is included at data\sample_invoices.xlsx — use it to test before using your real data.

3

Configure settings

Fill in the Settings fields. At minimum, set the Field Order to match the Tab order of fields in your application, and set the correct keyboard shortcuts for New Record and Save.

Click Save Config to save your settings so you don't need to re-enter them next time.

4

Do a dry run first

Check the "Dry run" checkbox and click ▶ Run. This validates your spreadsheet and config without the agent actually clicking anything. Fix any errors shown in the log.

5

Run for real

Uncheck "Dry run", open your target application and navigate to the data entry screen, then click ▶ Run. The agent will start entering data row by row.

⚠️
Don't touch the mouse or keyboard while the agent is running. Moving the mouse to the top-left corner of the screen will trigger an emergency stop (PyAutoGUI failsafe).

📊 Spreadsheet Setup

Preparing Your Data File

Your Excel (.xlsx) or CSV file must have column headers in the first row. The ERP Data Entry workflow expects these columns:

Column Name Required Description Example
invoice_numberRequiredInvoice or record IDINV-2026-001
vendor_nameRequiredSupplier or vendor nameAcme Corporation
invoice_dateRequiredDate in any common format2026-01-15
amountRequiredInvoice amount (number)1500.00
descriptionOptionalLine item descriptionOffice supplies
cost_centerOptionalCost centre codeCC-001
purchase_orderOptionalPurchase order numberPO-5001
💡
Column names don't match your spreadsheet? You can rename columns in your spreadsheet to match the names above, or ask your developer to add a column_map entry to the config file to map your existing column names automatically.

A sample file is included at data\sample_invoices.xlsx with 10 rows of test data. Use it to verify the agent is working before switching to your real data.

Saving and Loading Configs

Click Save Config to save your current settings to a .yaml file. Next time, click Load Config to restore them instantly. Keep one config file per workflow or per ERP system.

A ready-made config is included at config\erp_data_entry.yaml. Open it in Notepad to edit it directly.

🎯 Entry Modes

How the Agent Fills Fields

Choose the mode that best matches your application. You can change it in Settings at any time.

⌨️

Tab Mode

The agent presses Tab to move between fields, typing data into each one in order. Works with virtually every desktop ERP and accounting application.

Best for: Most desktop ERP apps (SAP, MYOB, Xero desktop, etc.)

🖼️

Template Mode

The agent finds each field by matching a screenshot image of its label or button. More reliable when Tab order varies.

Best for: Apps with a consistent visual layout where Tab order is unreliable.

🔍

OCR Mode

The agent reads text on screen to find field labels, then clicks next to them to enter data. Requires Tesseract OCR to be installed.

Best for: Web-based ERPs and apps where templates are impractical.

If the agent is clicking in the wrong place, quickly move your mouse to the top-left corner of the screen. This triggers an immediate emergency stop (PyAutoGUI failsafe). The application will show an error in the log.

🐍 Python PATH Error

Fixing "Python is not recognised" Errors

This is the most common issue. The new install.bat automatically searches for Python in over 15 common locations — so in most cases it will find it even if PATH is not set. But if it still fails, follow these steps:

Option A — Reinstall Python with PATH enabled (easiest)

1

Download Python again

Go to python.org/downloads and download the latest installer.

2

Run the installer — check the PATH box

On the very first screen, before clicking anything else, check the box at the bottom:

☑️
"Add Python to PATH" — this box must be checked

Then click Install Now.

3

Run install.bat again

After Python is reinstalled, double-click install.bat again.

Option B — Add Python to PATH manually

If Python is already installed but not in PATH:

Windows Search → "Edit the system environment variables"
1. Press Win + S, type: Edit the system environment variables
2. Click "Environment Variables..."
3. Under "User variables", select "Path" and click Edit
4. Click New and add the path to your Python folder, e.g.:
   C:\Users\YourName\AppData\Local\Programs\Python\Python312\
   C:\Users\YourName\AppData\Local\Programs\Python\Python312\Scripts\
5. Click OK on all dialogs, then restart your computer
🔧 Troubleshooting

Common Issues & Fixes

The app window doesn't open
Make sure you ran install.bat first and it completed without errors. Then try Run Desktop Agent.bat again. Check logs\desktop_agent.log for the error message.
The agent types in the wrong fields
The Field Order setting doesn't match your ERP's Tab order. Open your ERP, click on the first field, then press Tab repeatedly and note the order the cursor moves through fields. Update Field Order to match that sequence exactly.
The agent types too fast and the ERP misses characters
Increase the Typing Speed setting from 0.03 to 0.08 or higher. Also try increasing Delay Between Rows to give the ERP more time to process each record.
Some rows fail but others succeed
Check the log for the specific error. Common causes: the ERP showed a popup or dialog that wasn't dismissed, a required field was empty in the spreadsheet, or the ERP was slow to respond. Increase Max Retries to 3 and Delay Between Rows to 1.0.
The agent stopped halfway through
Tick "Resume from last completed row" and click Run again. The agent will automatically continue from where it stopped — no rows will be duplicated.
install.bat says "Package installation failed"
Right-click install.bat and choose "Run as administrator". If that doesn't work, check your internet connection and temporarily disable antivirus software, then try again.
Where are the log files?
Logs are saved to the logs\ folder inside the application directory. desktop_agent.log contains the full run history. Error screenshots are saved to logs\errors\ automatically when a step fails.
➕ For Developers

Adding a New Workflow

New workflows appear in the app's dropdown automatically — just drop a single Python file into the workflows\ folder. No other files need to change.

workflows\my_workflow.py
from engine.workflow_base import WorkflowBase, WorkflowResult
from core.error_handler import StepContext

class MyWorkflow(WorkflowBase):

    # These three properties are required
    @property
    def name(self): return "my_workflow"

    @property
    def description(self): return "Fills the XYZ system from a spreadsheet."

    @property
    def required_columns(self): return ["id", "value"]

    def setup(self, context):
        # Open your application, navigate to the entry screen, etc.
        context.input.hotkey("ctrl", "n")
        context.wait.medium_pause()

    def process_row(self, row, context) -> WorkflowResult:
        # This runs once for every row in the spreadsheet
        with StepContext("Enter ID", context.errors):
            context.type_into_field(row["id"])
            context.input.tab()

        with StepContext("Enter Value", context.errors):
            context.type_into_field(row["value"])
            context.input.hotkey("ctrl", "s")

        return WorkflowResult(row["_row_index"], success=True)

    def teardown(self, context, summary):
        # Called once after all rows are done
        context.input.hotkey("alt", "F4")

The context object gives you access to everything:

Method / PropertyWhat it does
context.type_into_field("value")Clear the current field and paste a value via clipboard
context.input.tab()Press Tab to move to the next field
context.input.hotkey("ctrl","s")Press a keyboard shortcut
context.find("templates/btn.png")Find a button by screenshot template → returns UIElement
context.wait_for("templates/btn.png")Wait until a button appears, then return it
context.find_and_click("templates/btn.png")Wait for a button and click it
context.find_text("Submit")Find text on screen via OCR → returns UIElement
context.wait.sleep(1.5)Wait 1.5 seconds
context.wait.wait_for_stable_screen()Wait until the screen stops changing
context.capture()Take a screenshot → returns NumPy array
